# Corpuz & Volante E-Commerce

React remake of the original HTML store. The old HTML files in the parent folder were left unchanged.

## Demo accounts

- Customer: `user@example.com` / `user123`
- Seller: `seller@example.com` / `seller123`

## Local run

```bash
cd ecommerce-react
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy the `dist` folder to Netlify, or connect this folder as the Netlify publish root with build command `npm run build` and publish directory `dist`.
